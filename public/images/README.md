# Photos go here

- `programs/` — photos for each program page
- `events/` — photos for the Past Events gallery
- `team/` — board member headshots
- `general/` — homepage and About page photos

After adding a file here, write its path in the matching file in the
`content/` folder, e.g. `src: "/images/events/bbq-2025.jpg"`.

See EDITING.md at the project root for the full guide.
